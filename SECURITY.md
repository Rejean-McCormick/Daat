# Security policy — alpha release

DaaT v0.3.0 is an **offline/in-process security-gated integration toolkit**; it is not a trusted public listener, IdP, policy service, audit broker, or certified gateway. Do not process genuine student, identity, financial, or medical records until owner integration and independent security review are complete.

Report vulnerabilities privately to the repository maintainer through their chosen GitHub private security-reporting channel. Do not open a public issue that includes credentials, students' details or active exploit data.

No production credentials or private test databases are included. The release includes pinned read-only IK owner contract copies; their redistribution permission must be confirmed before public distribution.

See [Security boundary](docs/20-SECURITY-BOUNDARY.md), [Threat matrix](docs/23-THREAT-AND-TRUST-MATRIX.md), and [Release validation](RELEASE-VALIDATION.md).
